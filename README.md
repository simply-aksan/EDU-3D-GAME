 # EDUZONE — Dunia Edukasi Interaktif 🎮📚

Platform web game edukasi Isometric 2.5D Pixel Art 16-Bit interaktif berkinerja tinggi dengan 5 dunia biom, kustomisasi karakter 3D/Pixel, 20 slot mini-game siap main, dan Universal Question Engine untuk pembelajaran yang seru dan adaptif.

---

## 🌟 Fitur Utama

- **5 Dunia Biom Unik**:
  - Kota Ilmu Modern (Matematika & Logika)
  - Lembah Sains Purba (IPA & Eksperimen)
  - Kepulauan Nusantara (Budaya & Geografi)
  - Hutan Aksara (Bahasa & Literasi)
  - Galaksi Cyber (Teknologi & Informatika)
- **20 Mini-Game Edukasi**:
  - Lari Kilat (Speed Quiz)
  - Jembatan Logika
  - Pasar Pintar (Manajemen Belanja & Diskon)
  - Detektif Sejarah
  - Jatuh Bangun (Platformer Kuis)
  - Boss Battle Kolosal & Mode Mini-Game lainnya!
- **Studio Guru (Teacher Studio)**:
  - Input & kustomisasi paket soal sendiri.
  - Generator Prompt AI untuk integrasi pembuat soal otomatis via LLM.
  - Ekspor/Impor format JSON dan URL hash instan untuk dibagikan ke siswa.
- **Kustomisasi Karakter**:
  - Seragam/Kostum (SD, SMP, SMA, Pramuka, Kimono, dsb.)
  - Aksesoris kepala & aura karakter.
  - Pet pendamping (Kucing, Robot, Naga Kecil, dsb.)
- **Rapor & Sertifikat Digital**:
  - Unduh sertifikat pencapaian format kartu/PNG.
  - Bagikan hasil belajar ke WhatsApp dengan sekali klik.

## 🚀 Cara Menjalankan Secara Lokal

### Prasyarat
- [Node.js](https://nodejs.org/) (versi 18 ke atas disarankan)
- npm (bawaan Node.js)

### Langkah Instalasi & Menjalankan

1. **Clone repository:**
   ```bash
   git clone https://github.com/simply-aksan/EDUZONE-education-game.git
   cd EDUZONE-education-game
   ```

2. **Install dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan development server:**
   ```bash
   npm run dev
   ```

4. **Buka di browser:**
   Akses `http://localhost:3000` melalui browser favorit Anda.

---

## 🛠️ Script Tersedia

- `npm run dev` : Menjalankan server development Vite lokal pada port 3000.
- `npm run build` : Melakukan kompilasi dan bundling aplikasi untuk produksi ke folder `dist/`.
- `npm run preview` : Meninjau hasil build produksi secara lokal.
- `npm run lint` : Memeriksa kesesuaian tipe kode dengan TypeScript (`tsc --noEmit`).

## 🧰 Teknologi yang Digunakan

- **Frontend Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Dev Server**: [Vite 8](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **3D Graphics & Visuals**: [Three.js](https://threejs.org/) + HTML5 Canvas Isometric Engine
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: [Motion](https://motion.dev/)
