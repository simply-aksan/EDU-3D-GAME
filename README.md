# EDUZONE — Dunia Edukasi Interaktif 🎮📚

Platform web game edukasi Isometric 2.5D Pixel Art 16-Bit interaktif berkinerja tinggi dengan 5 dunia biom, kustomisasi karakter 3D/Pixel, 20 slot mini-game edukasi siap main, dan Universal Question Engine untuk pembelajaran yang adaptif, seru, dan menyenangkan.

---

## 📸 Panduan Antarmuka & Fitur Game (Visual Tour)

EDUZONE dirancang dengan antarmuka modern bernuansa gelap (*sleek dark UI*) yang ergonomis, responsif di desktop maupun perangkat sentuh (HP/tablet), dan kaya elemen visual interaktif.

### 1. Peta Dunia Utama (Open-World Hub Isometrik)
Panggung utama tempat pemain dapat berjalan bebas, mengumpulkan buku pengetahuan, berinteraksi dengan mentor, dan memasuki gedung kuis:
- **5 Gedung Mata Pelajaran**:
  - 🏛️ **Menara Matematika** — Tantangan logika, aljabar, dan berhitung cepat.
  - 🏛️ **Pusat Sirkuit Koding** — Pemrograman dasar, pola logika, dan algoritma.
  - 🏛️ **Kubah Sains & Kimia** — Eksperimen IPA, fisika, dan biologi.
  - 🏛️ **Balai Bahasa & Sastra** — Pemahaman literasi, kosakata, dan tata bahasa.
  - 🏛️ **Museum Nusantara** — Sejarah kebangsaan, wawasan pahlawan, dan budaya bahari.
- **Warga & Mentor NPC Interaktif**:
  - 👨‍🏫 **Pak Guru Budi** — Wali Kelas Matematika & Logika.
  - 👩‍🔬 **Kak Siti Peneliti** — Mentor Laboratorium Eksperimen Sains.
  - 👩‍💻 **Kak Dewi Koding** — Arsitek Algoritma & Sirkuit Pemrograman.
  - 🧭 **Nakhoda Aris** — Sejarawan Bahari & Ekspedisi Nusantara.
- **Koleksi & Eksplorasi**:
  - Kubus Melayang **Buku Ilmu** (+30 Koin per buku) yang tersebar di peta.
  - Monumen Kristal Tengah sebagai pusat orientasi peta dunia.
- **Top Bar HUD Ergonomis**:
  - Tombol **Beranda**, Indikator **Bintang (★)**, Dompet **Koin (🪙)**, Akses Cepat **Shop**, Kontrol **Zoom Kamera (100%)**, **Toggle Suara/Audio**, **Layar Penuh (Fullscreen)**, dan Tombol **Sidebar Menu**.

---

### 2. Layar Pembuka (Title Screen Modal)
Tampilan modal selamat datang saat pertama kali membuka aplikasi:
- **Statistik Cepat**: Menampilkan total bintang terkumpul dan jumlah paket soal aktif (misal: `★ 20 · 📚 36 Soal`).
- **Tombol "Mulai"**: Langsung melompat ke dunia penjelajahan isometrik.
- **Tombol "20 Games"**: Membuka katalog lengkap pilihan mini-game dalam satu klik.
- **Tombol "Guru" (Teacher Mode)**: Mengakses Studio Guru untuk pengelolaan soal mandiri.

---

### 3. Pilihan 5 Dunia Biom (Sidebar "Dunia")
Pemain dapat berpindah biom kapan saja melalui tab **Dunia**, mengubah tema grafis lantai, pencahayaan, dan latar belakang:
1. **Kota Ilmu** — Metropolis Sains & Teknologi modern berarsitektur siber.
2. **Samudra Biru** — Eksplorasi bawah laut tropis dengan terumbu karang hidup.
3. **Stasiun Angkasa** — Koloni masa depan di Bulan dan sabuk asteroid.
4. **Rimba Tropis** — Hutan hujan lebat dan gua kapur eksotis endemik Nusantara.
5. **Kepulauan Nusantara** — Pelayaran bahari kapal pinisi, candi megah, dan pesisir kepulauan.

---

### 4. Menu Pengaturan & Navigasi (Sidebar "Menu")
Pusat kendali kenyamanan bermain dan utilitas edukasi:
- **Shop & Kustomisasi Karakter**: Akses langsung ke ruang lemari dan toko avatar.
- **Kontrol Sentuh Layar**: Pilihan mode `Otomatis` (aktif di layar sentuh), `Tampil` (menampilkan virtual joystick & tombol aksi), atau `Sembunyi` (khusus keyboard/mouse).
- **Zoom Kamera**: Tombol pembesaran `-` / `+` serta tombol persentase untuk menyesuaikan bidang pandang.
- **Materi Belajar**: Ringkasan teori materi esensial sesuai kurikulum sekolah.
- **Mode Guru (Teacher Studio)**: Input kurikulum, pembuat prompt AI, dan editor JSON kuis.
- **Rapor & Sertifikat**: Ringkasan nilai, analisis kekuatan mapel, unduh kartu sertifikat prestasi, dan tombol bagikan langsung ke WhatsApp.
- **Aksi Cepat Bawah**: Tombol cepat untuk *Mute Audio*, *Layar Penuh*, *Ulangi Sesi*, dan *Kembali ke Beranda*.

### 5. Katalog Lengkap 20 Mini-Game (Sidebar "20 Games")
Setiap mini-game dilengkapi genre unik, instruksi tombol, dan pencapaian 3-bintang:

| Slot | Nama Mini-Game | Kategori Genre | Deskripsi Mekanisme Gameplay |
|:---:|:---|:---|:---|

| **03** | **Jatuh Bangun** | *3D Tower Survival* | Panjat menara heksagonal vertikal. Setiap jawaban tepat mengangkat karakter ke lantai atas; jawaban keliru membuat pijakan retak dan runtuh! |
| **04** | **Detektif Kota Ilmu** | *3D Mystery Investigation* | Olah TKP forensik di 3 lokasi kota, cocokkan alibi 4 tersangka, pecahkan bukti soal, lalu seret pelaku utama ke meja hijau. |
| **05** | **Pasar Nusantara** | *3D Shopkeeper Math Sim* | Simulasi jual beli di warung tenda tradisional. Hitung cepat total belanja, diskon persenan, dan kembalian uang pelanggan NPC. |
| **06** | **Jembatan Juara** | *3D Island Glass Bridge* | Lintasi jembatan 6 baris panel kristal di atas jurang samudera dengan menginjak panel yang memuat jawaban valid. |
| **07** | **Pertahanan Kastil (Arsena Sains)** | *3D Tower Defense* | Kendalikan meriam partikel kuantum untuk menembak gelombang monster kegelapan dengan peluru rumus dan konsep sains yang cocok. |
| **08** | **Balap Roket Galaksi** | *3D Space Flight* | Kemudikan pesawat antariksa menembus cincin wormhole koordinat bintang dan hindari serpihan asteroid. |
| **09** | **Arsitek Menara** | *3D Block Stacker* | Tumpuk balok geometri presisi tinggi. Jawab pertanyaan sudut & volume untuk memperkokoh fondasi pencakar langit. |
| **10** | **Labirin Minotaur** | *3D Procedural Maze* | Cari jalan keluar dari labirin labirin kuno sambil menjawab pos pemeriksaan untuk membuka pintu gerbang terkunci. |
| **11** | **Panahan Katapel Fisika** | *3D Parabolic Slingshot* | Tentukan sudut elevasi dan gaya lenting katapel proyektil untuk mengenai sasaran target hukum gerak fisika. |
| **12** | **Sirkuit Logika (Robot Coder)** | *3D Isometric Grid Puzzle* | Susun balok instruksi kode (Maju, Putar Kiri, Putar Kanan, Looping) untuk mengantarkan robot penjelajah ke stasiun tujuan. |
| **13** | **Selam Samudra (Submarine Sonar)** | *3D Underwater Sonar* | Selami palung terdalam samudra, gunakan sensor frekuensi sonar untuk mendeteksi bioma laut langka. |
| **14** | **Koki Kimia (Lab Eksperimen)** | *3D First-Person Lab* | Campurkan senyawa reaktif dalam tabung reaksi dengan takaran molaritas yang seimbang tanpa memicu ledakan lab. |
| **15** | **Ekspedisi Pinisi (Peta Bahari)** | *3D Naval Navigation* | Kemudikan kapal tradisional Pinisi menelusuri rute rempah nusantara menggunakan petunjuk kompas dan garis lintang-bujur. |
| **16** | **Penjaga Gawang Pintar** | *3D Stadium Penalty* | Jadilah kiper legendaris! Prediksi arah bola tendangan penalti lawan dengan menyelesaikan soal kecepatan vektor secara kilat. |
| **17** | **Pabrik Sortir (Conveyor Sorter)** | *3D Industrial Automation* | Atur tuas rel berjalan otomatis untuk memilah paket material industri berdasarkan kategori klasifikasi yang benar. |
| **18** | **Tebak Bangun & Bayangan** | *3D Spatial & Laser* | Tembakkan sinar laser melewati prisma optik dan cocokkan bentuk proyeksi bayangan ruang dimensi tiga. |
| **19** | **Tarik Tambang Juara** | *3D Competitive Tug-of-War* | Adu cepat dan ketepatan menjawab pertanyaan tim demi menarik tali lawan melewati garis batas netral. |
| **20** | **Arena Boss Akhir (Raksasa Ilmu)** | *3D Action Quiz Boss Battle* | Pertarungan pamungkas melawan Raksasa Ilmu! Hancurkan 3 perisai pelindung boss dengan serangan kombo jawaban benar beruntun. |

### 6. Shop & Kustomisasi Karakter (3D Pixel Avatar Studio)
Ruang lemari interaktif dengan **Pedestal Pratinjau 3D Langsung**:
- **Statistik Profil**: Menampilkan Nama Karakter (dapat diubah), Koin terkumpul, Level Karakter, Total Bintang, dan Bar Progres XP.
- **Fitur "Coba Pakai"**: Pemain dapat mencoba pakaian atau aksesoris terlebih dahulu pada model 3D sebelum memutuskan membeli.
- **5 Kategori Item Koleksi**:
  1. 🎽 **Kostum**: Seragam SD, Seragam SMP, Seragam SMA, Pramuka Lengkap, Batik Emas, Kosmonot Sains, Zirah Ksatria Nusantara, Setelan Ninja Siber.
  2. 👑 **Topi / Kacamata**: Blangkon Tradisional, Topi Wisuda, Helm Antariksa, Kacamata Cyber Hologram, Mahkota Emas.
  3. ✨ **Aura Karakter**: Api Semangat, Partikel Bintang Cyber, Pusaran Air Mistis, Kristal Pelindung.
  4. 🐾 **Pet & Drone Pendamping**: Kucing Oranye, Robot Drone AI, Anak Garuda, Peri Ilmu.
  5. ⚔️ **Alat / Palet Warna**: Kuas Pelukis Kode, Tongkat Penggaris Emas, Pena Kristal, serta berbagai tema palet warna kulit/rambut.

## 🚀 Cara Menjalankan Secara Lokal

### Prasyarat
- [Node.js](https://nodejs.org/) (versi 18 ke atas)
- npm (bawaan Node.js)

### Langkah Cepat
1. **Masuk ke folder project:**
   ```bash
   cd EDUZONE-education-game
   ```
2. **Install paket dependensi:**
   ```bash
   npm install
   ```
3. **Jalankan development server:**
   ```bash
   npm run dev
   ```
4. **Buka game di browser:**
   Akses tautan **`http://localhost:3000`**

---

## 🛠️ Script Perintah Tersedia

- `npm run dev` : Menjalankan server development lokal Vite (port 3000).
- `npm run build` : Mengompilasi dan membundel seluruh aset ke folder `dist/` untuk deploy produksi.
- `npm run preview` : Menjalankan preview lokal dari hasil kompilasi folder `dist/`.
- `npm run lint` : Melakukan type-checking TypeScript tanpa emit file (`tsc --noEmit`).

---

## 🧰 Arsitektur & Teknologi

- **Frontend**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Engine**: [Vite 8](https://vite.dev/)
- **Visual & 3D Rendering**: [Three.js](https://threejs.org/) + 2.5D Canvas Isometric Engine
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons & UI Feedback**: [Lucide React](https://lucide.dev/) + [Motion](https://motion.dev/)
- **Audio Engine**: Web Audio API Procedural Synthesizer (BGM & efek suara SFX tanpa dependensi file audio eksternal)
